# ⚡ JS Pokédex  

Este repositório é uma **Pokédex interativa desenvolvida com JavaScript, HTML e CSS**, consumindo a **PokeAPI** para exibir informações detalhadas sobre os Pokémon. Aqui você encontrará cards de Pokémon com estatísticas, evoluções, fraquezas, gênero e mais.  

## ✨ Demonstração  

> Funcionalidades da Pokédex:  
> - Lista paginada de Pokémon  
> - Cards individuais com detalhes: imagem, altura, peso, habilidades e estatísticas  
> - Visualização das evoluções de cada Pokémon  
> - Indicação das fraquezas por tipo  
> - Exibição de gênero do Pokémon

## 💡 Sobre  

A **JS Pokédex** é um projeto que permite explorar Pokémon de maneira interativa, consumindo dados diretamente da **PokeAPI**. Cada card exibe informações completas do Pokémon, incluindo tipos, fraquezas, estatísticas e evoluções.  

O objetivo do projeto é praticar **JavaScript assíncrono, manipulação de DOM, consumo de APIs e estilização de interfaces web**.  

---

## 🧠 Funcionalidades Desenvolvidas  

- Listagem de Pokémon com paginação (`load more`)  
- Cards detalhados com:  
  - Imagem e nome  
  - Tipos e fraquezas  
  - Altura e peso  
  - Habilidades  
  - Estatísticas com barras visuais  
  - Evoluções  
  - Gênero  
- Paginação dinâmica para navegar por toda a Pokédex  

---

## 🧪 Tecnologias Utilizadas  

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)  
- **API:** PokeAPI  
- **Estilização:** CSS personalizado  

---

## 🧭 Como Visualizar o Projeto  

Clone o repositório:

```bash
git clone https://github.com/JyojiTenguam/js-pokedex.git
cd js-pokedex
```

Em seguida, abra o arquivo `index.html` em seu navegador.

> Não há necessidade de servidor local; o projeto roda diretamente no navegador.
